# Test Project

A Node.js web app built with TypeScript and Next.js. The UI is React, and dependencies are installed with npm.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Next.js
- **UI:** React
- **Package manager:** npm

## Project structure

```
app/            routes, layouts, and pages
components/     shared React components
lib/            helpers and shared logic
public/         static assets
types/          shared TypeScript types
```

## Getting started

Install dependencies:

```bash
npm install
```

The Next.js app is not scaffolded yet. The current `package.json` only lists `dotenv`.
